# QFXSystemBar 1.14.1 验收说明

修正两个入口的战斗行为，并将 MRT 统一为白色透明底圆框图标。

- 宝库左键直接调用 `WeeklyRewardsFrame:SetShown(not frame:IsShown())`，支持战斗中打开／关闭，首次点击按需加载 `Blizzard_WeeklyRewards`。不通过 `WeeklyRewards_ShowUI`、`ShowUIPanel`、`HideUIPanel` 调度，从而避开 UIPanel 的战斗和面板适配限制。
- 对照客户端已安装的 `EllesmereUI/EllesmereUI.lua` 中 `EllesmereUI.ToggleGreatVault()`：EUI 同样在首次点击加载后直接切换显示。该实现不要求 EUI 启用。
- MRT 已加载时，战斗中直接使用 `MRT_MinimapClickFunction()`，兼容入口为 `SlashCmdList.mrtSlash("")`；和 MDT 一样，只有入口尚未就绪且需要加载时才检查战斗。安装版本 5330 的 `MRT.Options:Open()` 直接显示面板，不修改其内部行为。
- MRT 图标固定使用 `QFXSystemBar/Media/MicroMenu/MRT.blp`：纯白圆框与 MRT 字样、透明背景、128×128、八级 mipmap。原有四套主题、设置预览和全局图标颜色均保留纯白；不再读取原生橙色 `IconTexture`。

API 基线仍为 Retail Live 12.1.0.69933；[暴雪宝库面板源码](https://github.com/Gethe/wow-ui-source/blob/live/Interface/AddOns/Blizzard_WeeklyRewards/Blizzard_WeeklyRewards.lua) 的 OnShow／OnHide 负责刷新和交互事件。这里只切换已有暴雪面板的显示，不改受保护属性，不包装其函数。

回归检查覆盖：宝库首次点击加载、已加载战斗中打开／关闭、战斗中首次加载、禁止 UIPanel 路径；MRT 两种已加载入口在战斗中可调用、缺失核心不在战斗加载；白色图标在四套主题及预览中不被原生彩色图片替换。十组测试全部通过，21 个运行时 Lua 文件语法检查通过。图标的白色 RGB、透明 alpha、BLP 头和 mipmap 已检查。

版本在五个 TOC、核心版本文件、README 和安装包中统一为 1.14.1。不增加 SavedVariables 字段，不改按钮显隐和顺序。更改文件在同步到游戏前备份到工作区 `_backups/`，同步后核对 SHA-256；回退可按备份 `manifest.json` 覆盖对应旧文件。

游戏内仍需验证：重载界面，保留已启用的宝库／MRT；进战斗后分别点击宝库打开、关闭和 MRT 打开；检查 MRT 为白色圆框图标，并查看是否有污染或阻止动作报错。自动测试模拟点击分发，不能证明客户端受保护执行已通过。
