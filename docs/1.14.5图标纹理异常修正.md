# 1.14.5 图标纹理异常修正

用户的客户端截图显示新增图标下半部分有杂点和断裂，这是纹理显示异常，已经超出普通的边缘模糊。1.14.4 同时更换了 RAW3/BGRA 格式、尺寸和强制三线性采样，且沿用原资源路径；离线解码验证无法证明 WoW 客户端读取正确。具体是 RAW3 读取差异还是旧路径缓存，仅凭截图无法区分。上次将离线校验作为主要依据，验证不足。

修正采用现有主题图标已经使用的 BLP2/DXT5（encoding=2、alphaDepth=8、alphaEncoding=7），撤销强制 TRILINEAR。三个图标仍从原 SVG 渲染为 256×256，各级 mip 直接从 SVG 生成。使用 `MDT-256.blp`、`MRT-256.blp`、`GreatVault-256.blp` 新路径，避免复用旧纹理缓存，并移除替代的旧 BLP。原 SVG、白色透明底和 1.14.3 的归一化裁剪坐标均保留。

格式字段参照 [Pillow 的 BLP 解码实现](https://github.com/python-pillow/Pillow/blob/main/src/PIL/BlpImagePlugin.py) 和工作区中已正常显示的主题图标核对。检查包括第三方 Pillow 解码各 mip 的尺寸、边界、透明度及压缩误差，Lua 回归、语法、ZIP 和同步后 SHA256。离线校验不能替代客户端截图确认。

运行改动仅涉及核心图标路径和配置预览的默认采样。五个模块的 TOC 版本和 addon_version.txt 更新为 1.14.5，TOC 文件列表不变；SavedVariables、点击行为和排序不变。资源总计约 259.5 KiB。

旧文件在同步前备份到工作区 `_backups/`，同步仅涉及本次变动。回退时按备份 manifest 恢复被替换和删除的文件，并移除新加入的三个 `*-256.blp` 文件；无需迁移 SavedVariables。游戏内先 `/reload`，检查菜单及设置预览的三个图标。若客户端仍缓存旧资源，可完全退出游戏再登录。
