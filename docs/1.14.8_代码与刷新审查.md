# 1.14.8 代码与刷新审查

用户于 2026-10-10 授权检查、修复并正式推送发布。本次将五模块正式版本统一更新至 1.14.8；今后开发修改仍保持版本号，只有正式发布才递增。

## 修复与清理

- 信息条 FPS 提示原来只有 OnLeave 取消计时器。关闭或重排信息条时，按钮隐藏不一定触发 OnLeave。现在 OnHide 同步清理，下一次刷新也检查可见性和提示框归属。
- 顶部菜单悬浮系统提示现在在按钮隐藏时立即停止刷新，菜单淡出至 alpha 0 时也停止；不会覆盖其他界面的提示。
- FPS 计时器记录当前所属按钮。旧按钮的隐藏事件不会取消新按钮的计时器，也不会关闭新提示。
- 时间和宝库的更新/清理增加提示框归属检查，避免异步更新重开已隐藏提示或清理其他窗口的提示。
- 信息条轮询在对应项关闭后自行取消，不继续无效唤醒。
- 删除无法跨版本存活的旧 ticker 兼容清理分支：计时器表只由当前固定的刷新项创建，客户端重载会重新初始化 Lua 环境，旧版本计时器不会传入新表。
- 删除不再读取的宝库 tooltipLines 元数据，以及十种语言中已被 Toggle MRT 替代的 Open MRT 提示词条。
- 发布配置明确排除 AGENTS.md、docs 和 .release，开发记录与本地备份不进入发行包。

## 保留的刷新

可见信息条只为已启用的 FPS（5 秒）、坐标（2 秒）、时间（60 秒）创建轮询；关闭相关内容或信息条会取消。菜单时钟更新（30 秒）、冒号闪烁（1 秒）及 FPS（5 秒）只服务可见菜单。FPS 悬浮提示的 1 秒刷新只在悬浮有效期间运行。

宝库、MRT、MDT 没有轮询计时器。宝库仅在悬浮期间监听奖励更新/大秘境完成事件，离开或隐藏后注销。菜单淡入淡出、设置拖动、预览拖动的 OnUpdate 只在对应动作期间运行；启动稳定定位采用有限的一次性延迟回调，不是持续轮询。其他徽标及集合石通过事件更新。

检查了自有运行模块中的局部函数和单个局部变量引用，未发现其他仅定义、无引用的明确死代码。QFXWidgets 是版本管理的共享工厂，保持规范源文件，不为本插件创建分叉。必要的兼容入口、公开模块接口及旧配置迁移保留。
