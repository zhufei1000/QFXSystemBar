# 1.14.7 MRT 再次点击关闭

已安装 MRT 5330 的 `Options.lua` 中，`MRT_MinimapClickFunction` 调用 `MRT.Options:Open()`，后者固定 `Options:Show()`，不是 toggle。`core.lua` 的空参数 `/mrt` 同样调用 Open，所以原来连续点击不会关闭。

QFX 左键处理现在先查看 MRT 注册的 `_G.MRTOptionsFrame`。若它已显示，直接 `Hide()` 并返回；未显示时仍调用 MRT 的小地图入口或 slash fallback，保持 MRT 自己的页面初始化。以真实可见状态为准，可以关闭由其他入口打开的窗口，也不会因用户按原关闭按钮而失去同步。右键和中键不参与切换。

MRT 的 `ExRTBWInterfaceFrame` 模板是普通 Frame，它自己的关闭按钮也是直接 Hide 父窗口；因此已加载 MRT 的打开/关闭继续支持战斗。缺少 MRT 核心时仍不在战斗中加载。客户端 API 基线核对 [Retail Live 12.1.0.69933](https://github.com/Gethe/wow-ui-source/blob/live/version.txt)，普通窗口可见性 API 参照当前 SimpleFrame 文档。未修改 MRT 本身。

变动运行文件仅为 `QFXSystemBar/QFXSystemBar.lua`。回归覆盖首次加载打开、再次点击关闭、战斗开关、slash fallback 开关、外部入口已打开、右键中键和未加载异常。执行 Lua 回归、运行文件语法检查、发行 ZIP 及同步后的 SHA256 校验。离线测试不能替代实际客户端点击检查。

五模块 TOC 和 addon_version.txt 更新至 1.14.7，TOC 文件列表不变。没有新增/删除运行文件或纹理，没有 SavedVariables 变更。同步前备份位于工作区 `_backups/`；按该次 manifest 恢复核心 Lua 和版本文件即可回退，无需玩家数据迁移。游戏内 `/reload` 后连续左键两次，再在战斗中重复检查；也可先从 MRT 小地图按钮打开，再点 QFX 的 MRT 按钮验证关闭。
