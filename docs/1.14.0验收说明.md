# QFXSystemBar 1.14.0 验收说明

此文记录 1.14.0 的初始实现；宝库／MRT 战斗点击和白色 MRT 图标的后续修正见 [1.14.1 验收说明](1.14.1验收说明.md)。

新增丝菌师的炉孢、宏伟宝库、MRT 入口和时钟中键重载，落实 NGA 反馈中的第一、第二批功能补齐。版本号已更新到全部五个模块的 TOC、核心版本文件与 README。

## 使用

- `/qfxbar` → 微型菜单 → 按钮顺序与显示：勾选“宏伟宝库”和“MRT”，拖动调整顺序。新按钮默认关闭。
- 宏伟宝库左键打开，再点关闭。使用暴雪面板和按需加载入口。
- MRT 左键打开插件面板。使用安装的 MRT 自带橙色圆环透明图标；图标元数据不可用时显示白色 MRT 字母备用图标，不随主题或全局图标颜色改变。
- 时钟左键打开日历、右键清理内存、中键重载界面。重载、宝库和 MRT 入口在战斗中提示暂不可用。
- 拥有丝菌师的炉孢（264367）后，可在炉石左／中／右键动作中选择，也会加入随机炉石池。随机动作继续检查角色可用性和冷却。

## 实现与来源

- `Defaults.lua` 增加玩具名单和两个可选按钮的默认值／迁移；仅补缺失字段，不重置现有顺序、显隐和动作。
- `Core.lua` 注册新按钮稳定 ID 和翻译映射；`QFXSystemBar.lua` 增加点击入口、图标解析和提示；Config 的按钮数据表复用现有 QFXWidgets 布局。
- 十个语言包补齐全部十个新键。炉孢优先使用客户端物品名；未缓存时使用对应语言的名称。
- 宝库图标为本项目原创白色宝箱轮廓，透明背景、128×128 DXT5 BLP、八级 mipmap。MRT 备用图标同规格。SVG 源文件和重建脚本留在仓库。
- Retail Live API 基线：[Gethe/wow-ui-source 12.1.0.69933](https://github.com/Gethe/wow-ui-source/tree/live)。[WeeklyRewards_ShowUI](https://github.com/Gethe/wow-ui-source/blob/live/Interface/AddOns/Blizzard_WeeklyRewards/Blizzard_WeeklyRewards_Bootstrap.lua) 负责加载／显示；关闭使用 `HideUIPanel`。[GetAddOnMetadata](https://github.com/Gethe/wow-ui-source/blob/live/Interface/AddOns/Blizzard_APIDocumentationGenerated/AddOnsDocumentation.lua) 读取 MRT 的 `IconTexture`。
- MRT 根据客户端已安装的 5330 版本核对：TOC 指向 `media/MiniMap.tga`，`MRT_MinimapClickFunction()` 打开选项，`SlashCmdList.mrtSlash("")` 作为兼容入口。不改 MRT 的私有表，不复制其图片到发行包。
- [炉孢物品数据](https://www.wowhead.com/item=264367/mycomancers-hearthspore) 确认物品 ID 和玩具属性；各语言备用名称来自同站物品数据。

## 验证

十组 Lua 回归测试通过，包含新增 `UtilityButtons_test.lua`、`Hearthspore_test.lua`；全部 21 个运行时 Lua 文件语法检查通过。新增按钮的首次加载、缺失插件提示、战斗限制、旧设置保留、四套主题和预览、炉孢拥有／可用／冷却条件已覆盖。十个语言包的新键无缺失；中文原有七个额外键保留。

游戏客户端交互仍需实际验收：重载后启用两个按钮，分别打开／关闭宝库和打开 MRT，查看图标与拖动顺序；在战斗中点击检查提示；对拥有炉孢的角色测试固定和随机动作。

SavedVariables 只增加 `isCustomMicroMenuGreatVault`、`isCustomMicroMenuMRT` 两个布尔设置；不手工修改玩家存档。模块数量和 TOC 加载顺序不变。主要剩余风险是游戏内 UI 交互，模拟测试不能证明客户端无污染报错。

客户端同步前的旧文件保存在工作区 `_backups/QFXSystemBar_client_backup_20261010_*`，其中 `manifest.json` 记录旧／新哈希和新增文件。回退时用备份中的同名文件覆盖客户端，按清单移除本次新增的四个图标文件，然后重载。
