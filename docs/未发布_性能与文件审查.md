# QFXSystemBar 未发布性能与文件审查

日期：2026-10-23。开发修改，版本保持 **1.14.11**。

## 结论与范围

检查了五个插件模块的 TOC 加载链、26 份 Lua、事件注册、计时器、OnUpdate、配置初始化、公开桥接与素材引用。确认存在隐藏后仍运行的信息条轮询、重复的数据查询与排序、退战斗重复应用，以及荔枝接管的重复原生布局与贴图写入，已针对这些路径优化。

未发现没有 TOC 引用的整份 Lua 文件。不能只凭文件名相似判定重复：主模块与 Config 各自的 ManagerSettings.lua 都有独立入口；管理中心专属适配、公开设置桥接、兼容性回退均保留。本次没有改动玩家配置、功能开关或 SavedVariables。

## 已修改的运行路径

| 路径 | 原有开销 | 修改后 |
| --- | --- | --- |
| 信息条 FPS、坐标、时间 | 只判断设置启用；父框体隐藏仍可能轮询 | 以实际按钮可见性决定计时器；隐藏时取消，显示时恢复，回调还有可见性兜底 |
| 菜单父框体显隐 | 时钟只检查透明度；隐藏 UI 后仍可能保留时钟计时器，FPS 取消后缺少显示恢复入口 | 同时检查实际可见性与透明度，并在宿主 OnHide/OnShow 中停止/恢复时钟和 FPS 刷新 |
| 三条信息条文本 | 同一个项目每条分别查询数据 | 每轮刷新按项目共享文本结果；区域项目保留逐按钮颜色更新，图标项目保留独立渲染 |
| 荔枝接管 | 相同状态同步也调用原生 Refresh、重新锚定标签、重写贴图/裁剪/颜色 | 缓存宿主尺寸、位置、有效缩放、字体、贴图与颜色；变化时更新，首次接管与换宿主仍完整处理 |
| 浮窗同步 | 部分荔枝路径重复同步；每次请求各自创建两次延时重试 | 直接进入当前提供方分支；一轮突发请求共享 0.2 秒、1 秒两个重试，保留即时同步 |
| 退战斗 | 三处监听分别触发菜单刷新、显隐处理 | 合并为一个入口，先处理暂缓的菜单修改，再合并应用显隐规则；战斗安全检查保留 |
| 顶部区域位置 | 初始化完成后仍监听加载、进世界、退战斗 | 完成后退订；有待处理锚点时重新监听并在完成后退订 |
| 集合石战斗修复 | 没有待修复面板也监听退战斗；未安装时仍监听插件加载 | 有待处理面板才监听退战斗；集合石缺席或已完成加载时退订无用加载事件；保留后续 EnableUIPanel 防护 |
| 系统提示内存/CPU 排序 | 命中数据缓存仍在每秒悬停刷新时对全部插件排序 | 数据重新扫描或 CPU/内存显示模式切换时才排序；原有 30 秒内存、3 秒 CPU 扫描缓存保留 |

另删除两个只返回 nil、没有实际实现或调用方的占位闭包：GetPremadeAddonIconTextureStub、GetPremadeAddonCountsStub。没有按文本出现次数批量删除对外 API、兼容代码或语言包。

## 文件与打包

五个模块目录原有 192 个文件，分发过滤后为 128 个。排除的 64 个文件共 **283,779 字节（约 277.1 KiB，未压缩大小）**：

- 54 份 GameIcons、Lucide、Tabler 主题 TGA：运行时选择同名 BLP；制作工具仍使用部分 TGA。
- 7 份 Config/Media PNG：当前设置界面使用对应 BLP。
- 3 份 SVG：MDT、MRT、GreatVault 的制作源图；运行时使用对应 BLP。

这些文件不由 Lua/TOC 加载，本身不会持续占用脚本 CPU；此次减少的是分发文件数、解压大小和冗余格式。原稿继续保存在项目中，未破坏图标生成工具，也未删除游戏目录里的旧素材。运行时需要的原版 TGA（如 MeetingStone.tga）保留。

本地 Python 打包与正式发布使用的 .pkgmeta 已统一排除规则。打包回归检查两者一致、所有 Lua/TOC 与必要素材齐全、ZIP 可读，并确认已有输出拒绝覆盖时原文件字节不变。

本地构建默认输出 `.release/QFXSystemBar_1.14.11_dev.zip`，可用 `--output` 选路径，覆盖需显式传 `--overwrite`。本次检查包是 `.release/performance-audit-dev.zip`。没有改写原正式 ZIP、版本号、标签或发布记录。

## 保留的必要刷新与设定

| 功能 | 周期与生命周期 |
| --- | --- |
| 菜单时钟冒号 | 1 秒；菜单与时钟可见时运行，隐藏停止 |
| 菜单时钟文本 | 30 秒；签名不变不重写文本，隐藏停止 |
| 菜单 FPS 附加文本 | 5 秒；按钮/附加文本启用且可见时运行 |
| 信息条 FPS、坐标、时间 | 分别 5、2、60 秒；本次加入实际可见性限制 |
| 提示信息 | 1 秒；悬停并持有提示框时运行，离开/隐藏/失去所有权停止 |
| 淡入淡出、拖动、控件短动画 | 活动期间临时 OnUpdate，结束清除；未发现主运行模块空闲常驻的逐帧刷新 |
| 登录及第三方兼容重试 | 有限次延时；不是常驻循环，保留解决加载顺序问题 |

QFXWidgets 只在 Config 按需加载，通过版本守卫复用共享工厂；本次不修改共享工厂。工厂部分弹出/按键捕获控件在创建后保留 GLOBAL_MOUSE_DOWN 监听，回调先检查打开/捕获状态；这是低频点击事件，不能等同于每帧或每秒刷新。

内存垃圾回收仅由用户点击触发，没有自动常驻强制 GC。CPU profiling 只在用户中键操作时切换；磁盘上的 Retail Config.wtf 未发现显式 scriptProfile 项，本次没有改动该全局设置，不能据此断言运行中客户端的实时值。
