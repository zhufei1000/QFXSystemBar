# 1.14.11 禁用提示报错修复

用户于 2026-10-19 要求正式发布。本次把五模块版本统一到 1.14.11，只包含一个缺陷修复，不改变设置项、存档结构或界面布局。

## 问题

共享设置工厂按 `type(tip) == "function" and tip() or tip` 取禁用控件的悬停提示。当启用判定只返回布尔、不返回原因时（例如聊天条的 `enabled = custom`），`tip()` 返回 nil，`or` 便把函数本身交给 `GameTooltip:SetText`，游戏内报：

```
bad argument #2 to '?' (Usage: self:SetText(text [, color, alpha, wrap]))
```

在 QFXSystemBar 设置页里，这条路径对应行按钮禁用提示、复选框禁用提示与颜色格子禁用提示三处。

## 修复

- 新增 `ResolveTooltipText`：函数与数字解析为字符串，其余取值（nil、表、函数返回 nil）一律视为无提示，宁可不弹出也不把非字符串传给 tooltip。
- 三处禁用提示改走该解析；`combatTooltip`、`limitTooltip` 等备用文案同样归一。
- 下拉与图标选择器新增 `ResolveList`：列表取值返回 nil 时退回空表，避免把函数当列表使用（`ipairs`／`#` 报错）。
