## 宝库悬浮信息

微型菜单的宝库按钮和信息条的宝库文字都显示团队副本、地下城、世界活动等当前有效类别的完成数，例如 `6/6`、`5/8`、`8/8`，以及已解锁奖励栏位总数。进度、目标数和栏位均读取 `C_WeeklyRewards.GetActivities()`，不写死赛季目标，也不为查询进度加载宝库窗口。达到目标后绿色显示，超额进度按目标数显示；有待领取奖励时额外提示。

API 基线为 Retail Live 12.1.0.69933；按 Blizzard 的 `progress >= threshold` 判断单个奖励栏位解锁。源文档：[WeeklyRewardsDocumentation.lua](https://github.com/Gethe/wow-ui-source/blob/live/Interface/AddOns/Blizzard_APIDocumentationGenerated/WeeklyRewardsDocumentation.lua)、[Blizzard_WeeklyRewards.lua](https://github.com/Gethe/wow-ui-source/blob/live/Interface/AddOns/Blizzard_WeeklyRewards/Blizzard_WeeklyRewards.lua)。API 数据尚未到达时显示加载提示。提示只在悬浮期间监听宝库更新和大秘境完成事件，离开或隐藏按钮后注销事件，没有常驻刷新计时器。

## 信息条入口

在 `/qfxbar` 的信息条页面，每条信息条的内容和排序设置均新增“宝库”“MRT”“MDT”。三项只显示文字，不创建图标；左键沿用微型菜单的开关处理，包括 MRT 再次点击关闭。战斗处理也共用已有实现：已加载的 MRT/MDT 保留自身战斗行为。

新增项默认未勾选，避免改变现有显示内容；已有排序和勾选保留，每条最多五项。迁移只在现有顺序数组中补全新 ID，重复迁移不改变结果。没有新增顶层 SavedVariables 字段。
