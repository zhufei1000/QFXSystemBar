# 1.14.6 图标缩小采样修正

1.14.5 的用户截图确认图标已不再花屏，但圆圈和斜线存在明显锯齿。保存的图标尺寸是 31 UI 单位，截图中轮廓约 26 屏幕像素。上一版在恢复 DXT5 时同时撤销了 TRILINEAR；256px 细线纹理大幅缩小时普通线性采样覆盖不足，是本次毛糙感的重要原因。截图不能给出 GPU 内部采样状态，诊断由代码变化与缩小采样模型共同支持。

只恢复 MDT、MRT、宝库的 TRILINEAR 采样；菜单、设置预览及拖动预览一致。1.14.5 的三个 DXT5 文件及路径字节不变，原 SVG、白色透明底、裁剪坐标、图标大小、排列和点击行为保留。不恢复 RAW3。

离线模型直接读取当前 DXT5 各 mip，以 1024px SVG 的像素覆盖平均作参考，在 24、26、28、31、36、48 像素及三种亚像素位置比较线性与三线性采样。模型平均 alpha RMS：MDT 36.91→25.43，MRT 29.13→20.07，宝库 36.40→25.86（0-255）。模拟显示锯齿减少；这些数字不代表真实客户端清晰度提升百分比。模拟脚本、结果和放大对比保存在 `.release/sampling_compare.py`、`.release/sampling-results.json`、`.release/sampling-comparison.png`。

API 按 [Retail Live SimpleTextureBase:SetTexture](https://github.com/Gethe/wow-ui-source/blob/live/Interface/AddOns/Blizzard_APIDocumentationGenerated/SimpleTextureBaseAPIDocumentation.lua) 的第四参数接口核对。缩小纹理与 mipmap 的原理参考 [Microsoft Texture Filtering](https://learn.microsoft.com/en-us/windows/win32/direct3d9/texture-filtering)；这是通用采样原理，未假设 WoW 使用 Direct3D 9。Retail API 基线沿用本轮已核对的 12.1.0.69933。

运行文件仅改 `QFXSystemBar/QFXSystemBar.lua` 和 `QFXSystemBar_Config/Config.lua`。五个模块的 TOC 版本及 addon_version.txt 更新为 1.14.6，TOC 文件列表不变，没有新增/删除资源，没有 SavedVariables 变更。回归检查滤波参数传递、其他图标默认滤波、四主题和原点击行为；语法、ZIP、同步 SHA256 亦检查。

同步前备份到工作区 `_backups/`，只复制实际变化文件。可按该版本备份 manifest 回退代码与版本文件；资源和 SavedVariables 无需迁移。游戏内 `/reload` 后检查正常大小及鼠标悬停的三个图标，同时查看设置预览。客户端观感仍需用户截图确认。
