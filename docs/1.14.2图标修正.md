# MRT 原标志白色图标修正

1.14.2 将上版的 MRT 字母圆框替换为原生标志的白色矢量描摹：保留圆环、倾斜横线和三条斜线，去掉彩色和黑色圆盘，背景及标志内空隙透明。

原图来自客户端 MRT 5330 的 `media/MiniMap.tga`。原文件外围透明，但内部黑色圆盘仍不透明，因此仅替换 RGB 会得到白色实心盘。本次以原图轮廓核对可编辑 SVG，再生成纯白 128×128 BLP 与八级 mipmap。先尝试的 imagegen 输出有杂点，未用于游戏资源。实际文件为 `tools/source_svg/MRT.white.svg` 和 `QFXSystemBar/Media/MicroMenu/MRT.blp`／`MRT.svg`。

运行代码、宝库和 MRT 战斗入口、配置及玩家存档不变。五个模块统一标注 1.14.2，安装包更新；复制到游戏目录前备份对应旧文件，复制后校验哈希。游戏重载后查看 MRT 图标即可。
