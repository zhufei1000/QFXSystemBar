# 1.14.4 图标清晰度修正

**客户端反馈：此版本随后出现纹理杂点和断裂，已由 1.14.5 撤销 RAW3 和强制滤波。以下记录描述当时的离线结果，不代表客户端验证通过。**

旧的三个图标与其他主题图标同为 128×128 DXT5，因此不能把视觉差异直接归为源图分辨率较低。细线轮廓、块压缩 alpha 和显示时采样共同影响观感。

本次保留已经确定的 SVG 图案及 1.14.3 的裁剪坐标，重新生成 256×256 无损 BLP2/BGRA。九个 mip 层级（256 到 1）各自从 SVG 渲染，避免逐级缩图累计的软化；透明像素的 RGB 也固定为纯白，避免采样混入黑边。三个图标在菜单、设置预览和拖动预览中使用 TRILINEAR，其他图标仍使用原来的默认滤波。

主重建脚本为 `tools/gen_white_icon.py`，原有 MDT／实用按钮生成脚本调用该脚本。MDT 署名和上游 GPL 保留。API 按 Retail Live 12.1.0 的 [SimpleTextureBase:SetTexture](https://github.com/Gethe/wow-ui-source/blob/live/Interface/AddOns/Blizzard_APIDocumentationGenerated/SimpleTextureBaseAPIDocumentation.lua) 四参数接口核对；[BLPConverter](https://github.com/Kanma/BLPConverter) 支持本次的 RAW3 无压缩 BGRA 格式。

原图案、白色透明底、归一化显示尺寸、按钮间距、点击行为和 SavedVariables 不变。三个资源总大小由约 67.5 KiB 增到约 1.0 MiB（运行时最多增加约 1 MiB 纹理数据）；发行 ZIP 会压缩重复的白色像素。

验证：逐 mip 检查 RGBA／透明度和完整数据，核对 alpha 与直接 SVG 渲染逐字节一致；检查裁剪仍完整包含图案；回归检查滤波传到菜单与配置预览、原有点击和排序通过。游戏内清晰度仍需重载后在实际 UI 缩放和图标大小下比较，离线检查不能替代客户端显示。

五个模块版本统一为 1.14.4。同步前将旧文件备份到工作区 `_backups/`，同步后校验哈希。若需回退，按备份清单恢复旧纹理、运行代码、配置代码及版本文件后重载。
