# Contributing

Thanks for helping improve QFXSystemBar.

## How to contribute

1. Fork this repository.
2. Create a branch in your fork.
3. Make your changes.
4. Open a pull request against `main`.

Please do not ask for direct write access unless we have already agreed to maintain the project together. Pull requests are the preferred way to contribute.
